## Featured Projects

### Intelligent Sprint Analysis Using Agentic AI

An Agentic AI system that analyzes GitHub issues, pull requests,
commits, and discussions to generate sprint intelligence.

**Technologies:** Python, LangGraph, LangChain, RAG, ChromaDB, Ollama, FastAPI

- Built an 11-agent LLM pipeline to analyze software development activity
- Implemented Retrieval-Augmented Generation using ChromaDB and Ollama
- Generated sprint risk assessments, sprint-health insights, and recommendations
- Developed FastAPI workflows connecting GitHub data ingestion, feature extraction, and analysis

### Trash Classifier

A Computer Vision application for classifying waste into six categories.

**Technologies:** Python, CNN, VGG16, Keras, OpenCV, Flask

- Developed a VGG16 transfer-learning CNN for waste classification
- Implemented image resizing, normalization, and data augmentation
- Used Adam optimization, categorical cross-entropy, and early stopping
- Integrated OpenCV preprocessing with a Flask application for image prediction

### LLM-Based Automatic Unit Test Generation

An LLM-based workflow for automatically generating and evaluating
Python unit tests.

**Technologies:** Python, Ollama, Llama 3, Streamlit, JSON

- Developed a workflow for extracting and sampling Python methods
- Generated pytest-style unit tests using multiple prompting strategies
- Evaluated 100 generated tests with 784 total assertions
- Performed failure analysis covering syntax errors, missing assertions, extra text, and other generation issues
- Built a Streamlit dashboard to visualize test validity, assertion metrics, edge-case coverage, and generated-test results

### Food Delivery Analysis

An exploratory data analysis project focused on food delivery data,
data cleaning, data enrichment, visualization, and identifying patterns
within the dataset.

**Technologies:** R, R Markdown, tidyverse, ggplot2, Data Analysis

- Performed data cleaning and preprocessing
- Investigated data inconsistencies and unrealistic geographic values
- Applied geographic validation and distance calculations
- Analyzed delivery-related patterns and data characteristics
- Created analytical reports and visualizations
